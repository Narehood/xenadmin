### Validation follow-up: proxy probe shutdown

The Windows job for documentation commit `b43769825` failed in the existing
proxy probe after six successful authentication cases: cancellation of a pending
accept surfaced as socket error 995 instead of `OperationCanceledException`.
See the [failed run](https://github.com/Narehood/xenadmin/actions/runs/36218147695).
This was a probe shutdown race, not an authentication assertion failure.

The probe now handles `SocketError.OperationAborted` only with requested
cancellation. Three regression cases compile its actual source and cover normal
cancellation, a concurrent listener stop (128 accept cycles in total), and an
unexpected stop that must still fail. The 12 real loopback authentication cases
pass after the fix; no production authentication or HA behavior changed. The PR
records fresh full-suite and hosted results on the final commit.
