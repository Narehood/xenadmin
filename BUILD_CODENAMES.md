# Build codenames

Each published (or intentionally stamped) build gets a unique Star Wars–*inspired* codename.
Names are original coinages — **do not** use Lucasfilm/Disney trademarks (no Skywalker, Vader, Tatooine, Mandalorian, etc.).

## How to assign

1. Pick an unused name from the **Candidate pool** below (or invent a new inspired coinage).
2. Append a row to the **Registry** with the version tag and codename.
3. Stamp the build: `-p:Codename=<Name>` (required for release; local defaults to `Local`).

Never reuse a registry codename.
